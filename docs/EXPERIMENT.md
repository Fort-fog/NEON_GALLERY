# NEON GALLERY 3D — локальный эксперимент с Qwen и STRATA

> Технические заметки по разработке интерактивной 3D-фотогалереи на домашнем ПК. Это описание реального сеанса работы, **не стандартизованный бенчмарк**.

## Проект

- **Назначение:** интерактивная неоновая 3D-галерея, локальный веб-сайт.
- **Сервер:** Go, стандартная библиотека (`net/http`).
- **Клиент:** HTML, CSS, JavaScript, локальная Three.js.
- **Контент:** 16 процедурно созданных SVG-постеров; генератор написан на Go (`tools/genassets/main.go`).
- **Проверки в ходе разработки:** сборка Go-сервера; генерация и проверка SVG; браузерные проверки через headless Chrome; поиск и исправление ошибок кадрирования 3D-сцены. Это наблюдения по журналу агента, а не независимый итоговый аудит всего сайта.

## Оборудование

| Компонент | Конфигурация |
|---|---|
| ОС | Ubuntu Linux |
| CPU | AMD Ryzen 7 5700X, 8 ядер / 16 потоков |
| GPU | AMD Radeon RX 7800 XT, 16 ГБ VRAM |
| RAM | 63 ГБ |
| PCIe | Gen4 x16 |

## Модель и исполнение

| Параметр | Значение |
|---|---|
| Приложение / движок | STRATA, HIP (AMD GPU) |
| Модель | Qwen3.8-Flash-Next |
| Квантизация | IQ3_S (GSQ-RCO) |
| Настроенный контекст | 128K токенов (в мониторе ~131,1K) |
| Режим размышления | High |
| Наблюдаемая скорость генерации | Примерно 20–35 токенов/с в разные моменты |
| Наблюдавшееся использование VRAM | Около 15,0–15,6 из 16 ГБ |
| Наблюдавшееся использование RAM | Около 55 из 63 ГБ |
| Наблюдаемая температура GPU | Примерно 35–41 °C в приведённых снимках монитора |

Скорость и нагрузка менялись на протяжении долгого сеанса; к концу сообщалось о высокой загрузке CPU/RAM и снижении скорости до ~20 токенов/с. Указанные значения **не являются усреднённым результатом исключительно задачи сайта**.

## Интерпретация токенов

В мониторе STRATA отображались миллионы **повторно использованных токенов входного контекста**. Это сумма кеш-хитов за множество обращений к модели, **не число уникальных созданных токенов** и **не стоимость одной задачи**. В сеансе выполнялись и другие задачи, включая аудит Go-проекта; поэтому общие счётчики нельзя приписывать только NEON GALLERY 3D.

## Запуск проекта

Из корня исходного проекта:

```bash
go run . -addr 127.0.0.1:18555
```

После запуска открыть `http://127.0.0.1:18555/`. Указанный порт — пример; он должен быть свободным.

Генератор исходных SVG-постеров:

```bash
go run ./tools/genassets -out ./generated-posters
```

Текущая реализация генератора создаёт **фиксированный набор из 16 постеров** на основе данных галереи. Повторный запуск детерминированный; генерация 1000 уникальных изображений пока не реализована.
