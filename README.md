# Неон фотогалерея 3D

Премиальное неоново-киберпанк демо фотогалереи в 3D-пространстве.
Полностью локальный проект: **Go (stdlib) + статика**, без Node.js, npm и сборщиков.
Все зависимости и изображения лежат в репозитории — интернет во время работы сайта не нужен.

## Запуск

```bash
cd A-strata-site
go run .
```

Открыть: **http://127.0.0.1:8080**

Полезные флаги:

```bash
go run . -addr :9000      # другой адрес/порт
go run . -open            # сразу открыть браузер (xdg-open / open)
```

Остановка — Ctrl+C (корректное завершение с graceful shutdown).


## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/gallery` | все работы + список категорий |
| GET | `/api/gallery?category=night` | фильтр по категории (регистр не важен) |
| GET | `/api/gallery?q=glass` | поиск по названию, автору, категории, описанию |
| GET | `/api/gallery?category=neon&q=ring` | комбинация фильтров |
| GET | `/api/health` | `{"status":"ok"}` для проверок |

Ответ:

```json
{
  "items": [
    {
      "id": 1,
      "title": "Rain Circuit",
      "category": "Neon",
      "description": "…",
      "author": "Vera Kuhn",
      "year": 2031,
      "accent": "#22e6ff",
      "image": "/assets/poster-01.svg",
      "w": 1200,
      "h": 800
    }
  ],
  "categories": ["Neon", "City", "Portrait", "Abstract", "Night"],
  "total": 16,
  "count": 16,
  "query": "",
  "category": ""

```

Категории и количество карточек приходят с сервера — чипы фильтра строит JavaScript,
так что добавление работы в `internal/gallery/gallery.go` автоматически расширяет и галерею, и фильтры.

## Управление

| Действие | Как |
|---|---|
| Осмотреться | зажать и тянуть мышью / пальцем ( orbit ), колесо или щипок — зум |
| Подсветка карточки | навести курсор — карточка приближается, растёт свечение, справа обновляется readout |
| Открыть просмотр | клик по карточке |
| Листать просмотр | `←` / `→`, кнопки, полоса миниатюр, свайп |
| Закрыть просмотр | `Esc`, клик по фону, крестик |
| Фильтр / поиск | чипы категорий, поле поиска (быстрый фильтр по названию, `/` — фокус на поиск) |
| Композиция | WALL (изогнутая стена) · CAROUSEL (кольцо) · FLOAT (объёмный рой) |
| Shuffle | перемешать порядок карточек |
| Reset View | вернуть камеру и композицию |
| Auto-orbit | выключить/включить автооблёт камеры |

## Как это устроено

- **Данные.** `internal/gallery` хранит датасет, `Filter(category, q)` отдаёт подмножество,
  `BuildResponse` добавляет пути к постерам и размеры.
- **Постеры.** `tools/genassets` рисует 16 SVG (город, неон, портрет, абстракция, ночь)
  из датасета Go — данные не дублируются, каждый кадр детерминирован (сид = `id`),
  и на выходе обязательно проходит XML-валидацию.
- **Сцена.** `static/app.js` строит Three.js-сцену: карточки (плоскость + аддитивное свечение +
  подпись), отражение в «полированном полу», сетка, световые лучи, частицы, туман.
  SVG растеризуются в canvas-текстуры — так карточки стабильно появляются в любом браузере.
- **Композиции.** WALL / CAROUSEL / FLOAT пересчитывают цели для карточек,
  позиции и повороты плавно интерполируются, вход — с каскадной задержкой.
- **Фильры.** Чипы и поиск debounce'ом обращаются к `/api/gallery`, карточки
  корректно добавляются и удаляются без пересборки сцены.
- **Fallback.** Если WebGL недоступен, вместо 3D показывается аккуратная сетка карточек
  с тем же lightbox. `prefers-reduced-motion` отключает автооблёт и дрейф.

## Перезапуск генератора постеров

```bash
go run ./tools/genassets           # перезапишет static/assets/poster-*.svg
go run ./tools/genassets -out /tmp/posters
```

## Проверено

- `go vet ./...` и `go build` — без ошибок и предупреждений.
- Сервер стартует, `/`, `/api/gallery`, `/api/health`, `/assets/*`, `/vendor/*` отдают 200.
- Загрузка страницы в headless Google Chrome: сцена собирается, ошибок в консоли нет,
  снимки экрана подтверждают рендер карточек, HUD и lightbox.
